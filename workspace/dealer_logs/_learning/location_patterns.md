## 2026-10-16 CarsCommerce / Dealer Inspire search feed: four places the store can be (N1.2 platform map)
- Per car, in order of reliability: `dealer.location` (store name or `<a href=site>Name</a><br/>street<br/>City, ST zip`; 47.8% of 4,400 sampled cars), `extra_fields.location_name` + one-line `dealer.address` (Fletcher Jones accounts only; 34.0%), and `dealer.feed_ccid` (100%: the CarsCommerce account of the store whose feed the car came from).
- `dealer.feed_ccid` is per store on most accounts and stable per VIN across accounts (334/335), and it groups a store's several source_ids (…transit, …pending, dealer code + MP feed). It is NOT per store on group feed accounts (Hendrick 546973, Five Star 6048266, Landers Fort Payne 5380003) and one feed (194600) carries two rooftops.
- Accounts can carry no label at all (East Tennessee Dodge 150600: 0/400), so the gate sees "no evidence" and keeps the whole group; only feed_ccid plus a learned own-feed hint can split them.
- The VDP host and the image photo account (vehicle-images.carscommerce.inc/<hash>-<acct>/) belong to the queried site, never the store: listing 2309549 shows 10 stores' cars all on www.mbontario.com and photo account 11000429.
- Evidence: workspace/cleanroom_2026_10/analysis/platform_evidence/carscommerce/field_map.json; dealer logs mbontario-com, mbbeverlyhills-com, easttennesseedodge-com, fjmercedes-com.

## 2026-10-18 DealerOn cosmos: the lot per car, and a second address source for franchise rooftops (N1.11)
- Per car: `VehicleCard.DealerLocatedAtId` + `VehicleLocation` + `DealerLocatedAtCity/State` name the lot; `DealerId` names the serving site. The SRP "Dealership" facet (the filters API) filters by VehicleLocation server side.
- Our parser drops these fields (dealer_on.py:196-252, N8.1), so verify a stored cosmos row with a live census VIN -> lot map (workspace/phase_runs/N1/N1.11/tools/cosmos_census.py) and not with the DB.
- Second address source when Google Places websiteUri is unavailable: the brand's retailer locator. Subaru: `https://www.subaru.com/services/dealers/distances/by/zipcode?zipcode=<zip>&count=5&type=Active` returns street, zip, lat/long and siteUrl; siteUrl host == dealer host is the same check as Places websiteUri.
- Evidence: workspace/dealer_logs/subaruofgallatin-com/location.md.
