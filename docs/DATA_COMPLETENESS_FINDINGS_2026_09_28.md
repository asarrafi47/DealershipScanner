# Data completeness and accuracy findings, 2026-09-28

Measurement set: `workspace/data_quality/incomplete_2026_09_28/` (computed 10:55-10:58 UTC today from a read-only session; the 8-shard fleet scan was still running, so today's numbers are a snapshot). Definitions follow `backend/scripts/dealer_pipeline.py`: KEY_FIELDS = price, trim, exterior_color; SECONDARY_FIELDS = interior_color, engine_description, transmission, drivetrain, fuel_type, body_style, description, stock_number, msrp, gallery (8+ URLs), mileage (used/certified only). Active = `cars.listing_removed_at IS NULL`. Missing = NULL or '' (price <= 0, gallery < 8 URLs). Platform = `dealer_recipes.provider_hint`. Nothing in this document was written to the database and no code was changed; every fix below is a recommendation.

Each hypothesis was verified against the live site with plain HTTP (curl_cffi chrome impersonation, at most a handful of requests per dealer, 2 s apart); saved pages and verdicts are in the per-hypothesis subfolders (`h1_dealer_outlier/`, `h1_msrp/`, `h2/`, `h3/`, `h4/`, `h5/`, `h6/`, `p1_probe/`, `p2_msrp/`, `p3/`, `v2_engine/`, `outliers/`).

## 7. Recommended changes to the incomplete_listings tally and verify_accuracy

Current tally (`05_tally_summary.json`, `05_tally_incomplete_listings_by_field.csv`, `05_tally_incomplete_listings_staleness.csv`): 21,023 rows, 12,506 on active cars, 8,517 orphan/removed; tracks 11 fields (body_style, cylinders, drivetrain, engine, exterior_color, fuel_type, make, model, price, transmission, trim) and none of msrp, description, gallery, stock_number, interior_color, mileage; it misses 13,531 active rows with a tracked field missing (10,401 engine_description, 1,335 trim, 1,263 body_style; 11,403 dealer_dot_com, 9,728 scraped today) and still holds 2,260 rows that are no longer missing anything; `incomplete_listings_meta` holds only `index_bootstrap_v1=1`.

Tally changes:

1. Stop counting: engine_description and cylinders on EVs; msrp on used/CPO and on providers whose feed has no msrp (jazel, overfuel, wp_vehicles_index, autowall, dealermasters, chapman in-transit); stock_number, msrp, gallery_8plus and vPIC fields on allocation VINs; description and gallery on chapman / autowall / wp_vehicles_index (until a VDP recipe exists); trim on rows where vPIC Trim/Series is present or `catalog_model_is_trimless()` is true; mileage on New rows.
2. Start counting: msrp on New rows, description, gallery_8plus (https photo URLs only, denylisted widgets excluded), stock_number on New non-allocation rows, interior_color, mileage on used/CPO when 0 or NULL (F12), `msrp == price` on used rows as "msrp copied from price".
3. Fix the write path so the tally is refreshed on every upsert and on every heal (today it lags: 13,531 misses, 2,260 stale hits); clear rows whose car is removed; populate `cars.missing_field_count` and `recovery_status` from the same computation; put the field list and its version into `incomplete_listings_meta`.
4. Report by recipe URL class, not provider_hint, until the hints are re-stamped (section 4).
5. Weight `data_quality_score` by the fields that actually fail (msrp on new, description, gallery).

verify_accuracy changes:

1. Drop as defects: AWD vs 4WD, 4x2 vs RWD/FWD (report informational), make/model alias pairs (alias table), "trim null but title has a token" (body words), "new with mileage > 300" (demo flag instead).
2. Add: Hybrid vs PHEV and Gasoline vs Mild HEV as first-class checks (finer fuel buckets); `cylinders` column vs the count named in engine_description (235 rows today); drivetrain / transmission / fuel_type placeholders ('Other', 'Direct Injection', 'G', 'UNL', ...); mileage = 0 on used; VIN shape (non-17-char, I/O/Q, letter serial) with an allocation classification instead of a decode failure; price < 1,000 on New and price > 1.5x MSRP; source_url pointing at a non-VDP page (finance page, SRP: VIN absent from the fetched HTML); description equal to a dealer's SEO boilerplate shared by many rows (toyotaofriverside: one string on 103 rows).
3. Always store cannot_assess separately from disagree (4,656 hybrid rows with blank vPIC electrification; GM BEV AWD/RWD), and alarm when a heal pass would rewrite more than 50% of a dealer's rows.
4. Run the vPIC override per batch and check the scanner log for "VIN facts failed" as a health metric (F04 went unnoticed for three days).
